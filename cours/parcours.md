# Parcours Vue 3 — De zéro à senior ESN

> Format : théorie concise + exercice pratique à chaque étape.
> Stack : Vue 3 + TypeScript strict + Composition API.
> 51 cours · 34 exercices · Tous lançables dans `App.vue`.
> Les exercices de renforcement (suffixe b) revisitent un concept sous un angle différent.

---

## 🧠 Méthodologie — Apprendre pour retenir

Ce parcours applique les principes des sciences cognitives. **Respecte ces règles** pour maximiser ta rétention :

| Règle | Pourquoi |
|-------|----------|
| **1 cours = 1 session** | Évite la surcharge cognitive |
| **24h entre chaque cours** | Sommeil = consolidation mémoire |
| **Tente AVANT de voir la solution** | L'effort de rappel ancre le souvenir |
| **Révise à J+1, J+7, J+30** | Courbe de l'oubli (Ebbinghaus) |

> ⏱️ = temps estimé (lecture + exercices 🎯). Prévois le double pour l'exercice principal.

### Comment réviser ?

**J+1** : Relis les sections **🎯 Pratique** du cours et refais 1-2 exercices de mémoire (sans regarder la solution).

**J+7** : Parcours le résumé en fin de cours. Peux-tu expliquer chaque concept à voix haute en 30 secondes ?

**J+30** : Refais l'exercice principal du module. Si tu bloques > 5 min, relis le cours.

## Cadre pédagogique

- TypeScript strict partout, zéro `any`.
- Théorie concise → exercice immédiatement après.
- Contextes variés : UI, logique métier, intégration API.
- 34 exercices (dont 6 exercices de renforcement ⟳) tous lançables dans `App.vue`.
- Exercices de renforcement : même concept, angle différent (composition, cas réel, complexité accrue).
- Objectif : être opérationnel en mission ESN niveau senior sur Vue 3 + écosystème.
